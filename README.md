# ETD Intercom for Home Assistant

Пользовательская интеграция Home Assistant для домофонов ETD Online.

Я написал её для того, чтобы двери, калитки, ворота и камеры ETD можно было использовать внутри Home Assistant, а не только через штатное приложение. Интеграция умеет получать список доступных объектов, создавать кнопки открытия и показывать видео с камер.

> Это неофициальный проект. Он не связан с ETD Online и использует интерфейсы сервиса, которые могут измениться без предупреждения.

## Возможности

- вход по готовому токену;
- вход по номеру телефона и SMS-коду;
- автоматическое добавление доступных домофонов;
- кнопки открытия дверей, калиток и ворот;
- камеры в Home Assistant;
- превью и живое видео;
- WHEP/WebRTC через прокси Home Assistant;
- ручное добавление объектов по ID;
- отдельная и обзорная Lovelace-карточки;
- возможность скрыть кнопку открытия у конкретного объекта.

## Установка через HACS

Добавьте репозиторий как пользовательский:

```text
https://github.com/WWWorm92/etd-intercom-home-assistant
```

Тип репозитория:

```text
Integration
```

После установки перезапустите Home Assistant.

Затем откройте:

```text
Настройки → Устройства и службы → Добавить интеграцию → ETD Intercom
```

Во время настройки можно выбрать вход по токену либо по телефону и SMS.

## Lovelace-карточка

Если ресурс не добавился автоматически, укажите его вручную:

```text
/etd_intercom/etd-intercom-card.js?v=0.8.3
```

Тип ресурса:

```text
JavaScript module
```

### Обзор всех объектов

```yaml
type: custom:etd-intercom-overview-card
title: Домофон
columns: 3
mobile_columns: 1
video_mode: whep
auto_start: true
auto_retry: true
height: 220
video_fit: cover
compact: true
open_text: Открыть
full_width: true
max_width: 1500px
```

### Одна камера и одна кнопка

```yaml
type: custom:etd-intercom-card
camera_entity: camera.etd_podiezd_2_camera
button_entity: button.etd_podiezd_2_open
title: Подъезд 2
video_mode: whep
height: 260
open_text: Открыть
```

Имена сущностей в вашей установке могут отличаться.

## Ручное добавление объектов

Откройте настройки интеграции:

```text
Настройки → Устройства и службы → ETD Intercom → Настроить
```

Формат одной строки:

```text
000270 | Подъезд 1 | mdi:door-open
001586 | Ворота | mdi:gate-open
```

Это полезно, когда нужный объект не возвращается в общем списке, но его ID известен.

## Режимы видео

- `preview` — статическое или периодически обновляемое превью;
- `iframe` — штатный плеер ETD внутри карточки;
- `whep` — прямой WebRTC-поток через прокси Home Assistant.

WHEP обычно даёт меньшую задержку, но сильнее зависит от доступности серверов ETD, токена и сетевой конфигурации.

## Безопасность

Не публикуйте:

- токены авторизации;
- SMS-коды;
- SIP-логины и пароли;
- прямые WHEP-ссылки;
- адреса и идентификаторы объектов, если по ним можно определить место установки.

Рекомендуется хранить Home Assistant за HTTPS и не открывать его наружу без дополнительной защиты.

## Известные ограничения

- интеграция зависит от неофициального API;
- видео может перестать работать после изменений на стороне ETD;
- доступные функции различаются для разных типов домофонов;
- входящие SIP-звонки пока не являются частью основной интеграции;
- проект тестировался прежде всего на моей собственной установке.

Сообщение об ошибке лучше прикладывать вместе с версией Home Assistant, журналом интеграции и типом объекта. Секреты из лога перед публикацией нужно удалить.

## Планы

- входящие вызовы через baresip/MQTT;
- события вызова в Home Assistant;
- автоматический выбор камеры при звонке;
- более удобная диагностика видеопотока.
